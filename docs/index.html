The butinage engine
InspectionColony

An agent you run 24/7 needs more than a chat loop

Plenty of projects give you tool calling. LaRuche's bet is that a node living on your machine needs an engine, a memory, a supervisor and reflexes — each one a first-class subsystem, each one auditable.

Butinage

A ReAct loop hardened for imperfect models

Native tool calling per provider with tolerant text fallbacks, client-side schema validation, an anti-loop sentinel, per-tool timeouts, token budgets, cooperative cancellation, live steering mid-run, and parallel scouts for deep research. An evals harness replays fixed missions against the real engine, so regressions get caught rather than guessed at.

109 tests
Mémoire

Cognitive memory with git time travel

Not a vector store bolted on: a map of nodes and facts over SQLite, hybrid recall fusing embeddings with full-text search, importance decay, and write-time supersede so an updated fact replaces the stale one instead of piling up beside it. Hebbian ranking reinforces only what was actually used in an answer. The whole map exports to markdown in its own git repo — git log is your agent's learning timeline.

LaReine

A supervisor that can send the work back

A judge reviews answers against an editable charter before you see them, and it has real leverage: it can order a fresh agentic run, it keeps the best-scoring draft so quality never regresses across retries, and it escalates when it is not confident. Its methodology score is grounded in which tools were actually called — not in what the answer claims.

Human seat
Veille

Reflexes that cost nothing at runtime

Describe a rule in plain language and it compiles once into a deterministic predicate tree. Weekdays, time windows, file appeared or changed, service down for N minutes, log patterns, HTTP status — combined with and/or/not. The only rule that ever calls a model is an explicit check leaf, and only once the deterministic prefix has already passed.

Compiled
Coffre

A security model that assumes the model will slip

Loopback by default, strict CORS, an auth guard on every mutating route, sanitized rendering, and sensitive tools behind a human approval gate. The vault gives the model names, never values: you write a key reference in chat, substitution happens at execution time, and if a tool output echoes a secret back it is masked before it can reach the context or the session file.
