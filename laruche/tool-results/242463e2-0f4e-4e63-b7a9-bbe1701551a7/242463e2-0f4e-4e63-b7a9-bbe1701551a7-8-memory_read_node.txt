### 1. Commandes de Console (Cheat Codes)
*Utilisation : Appuyez sur la touche tilde (~) pour ouvrir la console sur PC.*

**Commandes de base :**
- `tgm` : Mode Dieu (Invincibilité, ressources infinies).
- `player.setpos x y z` : Téléportation (remplacer par les coordonnées).
- `additem [ID_objet] [quantité]` : Ajouter des objets (ex: `additem 0000000f 1000` pour 1000 pièces d'or).
- `player.setlevel [niveau]` : Modifier le niveau du joueur.
- `kill` : Tuer la cible sélectionnée avec le clic gauche.
- `unlock` : Débloquer les portes ou coffres ciblés.
- `showinventory` : Afficher l'inventaire dans la console.
- `tcl` : Mode Spectateur (permet de traverser les murs et de voler).
- `settime [heure] [minute]` : Réinitialiser l'heure du jeu.

**Commandes Avancées (Attributs & Compétences) :**
- `setav [attribut] [valeur]` : Modifie directement la valeur d'un attribut (ex: `setav health 1000`). Ne fait pas progresser le niveau global.
- `advskill [ID_compétence] [quantité]` : **Recommandé.** Ajoute de l'expérience naturellement. Fait progresser la compétence ET le niveau global du personnage.
- `forceav [attribut] [valeur]` : Force la valeur d'un attribut.
- `modav [attribut] [quantité]` : Ajoute une quantité spécifique à un attribut.
- `incpcs [ID_compétence] [quantité]` : Augmente les points de compétence.

Pour gérer les Perks (compétences spéciales) via la console, utilisez les commandes suivantes :

1. **Ajouter un Perk spécifique** : `player.addperk [ID_du_perk]`

   - Alternativement, certains utilisent `player.setav perkpoints [Valeur]` pour définir un nombre précis de points.

*Note importante* : Pour les perks ayant plusieurs niveaux (ranks), les codes doivent être saisis dans l'ordre correct pour que le jeu les affiche correctement.
